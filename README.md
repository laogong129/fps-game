# FPS-game · 暮轨幸存者

在约 120×120 米的暮色雨后铁路街区中迎战八波怪物追击。利用住宅巷道、站台、天桥与可乘坐列车改变站位，击败最终 Boss、护卫和召唤物后获胜；玩家阵亡即失败。

在线试玩：[暮轨幸存者](https://laogong129.github.io/fps-game/)。使用支持 WebGL 的桌面浏览器，键盘和鼠标操作；首次打开需等待模型加载与追击路线准备。

当前版本已采用追击玩法。单局 12—18 分钟、枪械分工及新手理解仍待真实玩家验证，不能由自动化测试推断。试玩模板见 [PLAYTEST.md](PLAYTEST.md)，实际规则见 [PROJECT.md](PROJECT.md)。

## 本地运行

需要 Node.js 22.12+、npm，以及支持 WebGL 和鼠标指针锁定的桌面浏览器。

```powershell
npm ci --cache .cache/npm
npm run dev -- --host 127.0.0.1 --port 5173
```

打开 [本地游戏](http://127.0.0.1:5173/fps-game/)。首次加载会载入模型并分批准备追击路线，按钮显示进度；完成后点击“进入暮色街区”，允许锁定鼠标。三枪使用 Quaternius 的同套低多边形模型，统一暗钢、枪灰与木色，素材来源和 CC0 许可见 [ASSET_CREDITS.md](ASSET_CREDITS.md)。模型未就绪时使用基础造型。

| 操作 | 按键 |
|---|---|
| 移动 / 冲刺 / 普通跳跃 | WASD / Shift / 空格 |
| 翻越 / 抓边 | 靠近对应障碍，前进＋空格 |
| 上下检修梯 | 接触梯口自动攀爬；离开后再次接触可反向通行 |
| 瞄准 / 射击 | 鼠标 / 左键；步枪支持按住全自动 |
| 三枪 ADS / 换弹 / 切枪 | 右键 / R / 1、2、3 |
| 提前开始下一波 | 备战按 G，或点击界面按钮 |
| 暂停 / 继续 | Esc；点击“继续战斗”重新锁定鼠标 |
| 重开 / 战报 | 结算按 Enter 或点击重开；导出按钮下载 JSON |

跑酷期间不能射击，仍会受伤。停站时可以从车门进入车厢、通过检修梯上下车顶；行驶中可在车内或车顶移动和射击，也能从车顶跳下。窗口允许双方射击，实心车壁与车顶挡弹。

列车起步和道口有灯声预警，切勿站在行驶车身前方或侧面。安全乘坐不会受撞击伤害；被撞时玩家损失 80% 最大生命，普通怪可被撞死，Boss 每趟最多损失 30% 最大生命。门口有人会延迟关门和发车。

## 规则速览

- 共 8 波；首局与每次清场后备战 15 秒。第 1—7 波分别生成 8、12、16、20、24、28、32 名基础敌人，第 8 波生成 Boss 与 18 名护卫，分裂和召唤另计。
- 敌人袭击玩家，可沿坡道和主通路追上高处。普通怪停站登车，Boss 留在固定场地以远程和召唤压制乘客。
- 三把枪：手枪精确点杀、霰弹近身击退、步枪持续压制。手枪开局，前两次升级至少一次提供新枪选项，玩家可以放弃。
- 子弹从实际枪口发射，手枪/霰弹/步枪初速分别为 230/240/560 米每秒，存在飞行时间、下坠和射程衰减；远处移动目标需要适当提前量。墙体和列车实心部位会挡弹，窗口可对射。三枪支持右键瞄准，移动、冲刺和连射会降低精度，停火后恢复。
- 经验球保留 20 秒，清场回收剩余经验，连续升级逐次选卡。血包保留 10 秒，满血不消耗；第 3、6 波在玩家附近合法落点生成补给箱。
- 只有生成队列、生成预警和全部活敌都清空才算清场。玩家死亡优先于同帧通关与奖励回血。
- 暂停、升级选卡和结算冻结战斗、列车及拾取计时；恢复时清除遗留输入。切出窗口也会暂停。

## 开发验证

```powershell
npm test
npm run build
npm run preview -- --host 127.0.0.1 --port 5174
```

`npm test` 使用 Node 内置测试运行器。生产构建输出到 `docs/`，预览为 `http://127.0.0.1:5174/fps-game/`。调试接口仅在开发服务器开放。

浏览器回归需要先在独立终端保持开发服务器运行，再执行：

```powershell
npm run test:browser
```

运行器使用系统 Microsoft Edge（默认 `msedge`）和已安装的 Playwright，不自动安装依赖或浏览器。如果 Playwright 来自 Codex 捆绑运行时，可在当前终端指定：

```powershell
$env:CODEX_WORKSPACE_NODE_MODULES = 'C:\Users\Hello\.cache\codex-runtimes\codex-primary-runtime\dependencies\node\node_modules'
npm run test:browser
```

可选环境变量：`FPS_TEST_URL`（默认 `http://127.0.0.1:5173/fps-game/?test`）、`FPS_BROWSER_CHANNEL`（默认 `msedge`）。生产预览启动后，执行 `npm run test:browser -- --production`，检查实际启动、资源、指针锁定与暂停，并确认没有开发调试接口。

自动化报告与截图保存在 `.cache/qa/`，以实际执行输出判断是否通过。它们验证规则和碰撞行为，不能代替画面审阅、性能评估或至少 5 名新手的试玩。结算战报 `fps-railway-run.json` 使用格式版本 2，全部留在本地。

技术栈：Vite、Three.js、原生 JavaScript。数值集中在 `src/config.js`，静态场景清单在 `src/game/railway-layout.js`，核心逻辑位于 `src/game/`。没有多人、建造、局外成长或游戏进度存档。
